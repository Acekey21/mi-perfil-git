Proyecto práctico de control de versiones con Git.

## Sobre el proyecto
Este repositorio forma parte de una práctica de control de versiones.

## Objetivos
- Practicar el uso de Git.
- Crear un historial de cambios organizado.
- Utilizar commits descriptivos.

## Tecnologías utilizadas
- Git
- Git Bash
- GitHub

## Estructura del proyecto
- README.md: documentación principal del proyecto.
- Historial de Git: registro de los cambios realizados.

## ¿Qué es Git?
Git es un sistema de control de versiones que permite registrar y administrar los cambios realizados en un proyecto.

## Aprendizaje
Esta práctica permite comprender el flujo de trabajo básico con Git y el uso de commits para registrar cambios.
